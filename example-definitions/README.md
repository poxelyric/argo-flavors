# Examples
Each example explores a different type of argocd architecture and has a guide for setting up the environment. The avatar example focuses on showing the basic usage and features of argocd-flavors and is easy to get started with. The other two focus on utilizing these features in order to adapt to different architectures.
### 🔥 Avatar
Deploy apps from a centrelized argocd. A quick start to explore the project.

### 🕶️ argocd agent
The recommended architecture for managing many many clusters. 

### 🐙 argo of argos
An alternative to argocd agent if you are not ready to adapt it. propegate apps to be managed by remote clusters by deploying app manifests with argocd instead of replicating them with agent.
